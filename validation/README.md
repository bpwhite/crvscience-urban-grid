# Validation Telemetry (`crvscience-urban-grid` v5.2.0)

Deterministic headless empirical validation artifacts generated by running `cargo test -p ug-core --test headless_validation` directly against the compiled Rust simulation workspace (`ug-core`).

## Test Protocols
1. **T1 (`t1_idm_mobil_fundamental_diagram_and_headway_invariant`)**: Evaluates the Intelligent Driver Model (IDM) car-following and MOBIL lane-changing fundamental diagram (flow, density, speed) across demand scaling factors while asserting a zero-collision minimum vehicle headway invariant across all active lanes and connectors.
2. **T2 (`t2_nfpa_1710_mclp_emergency_siting_optimization`)**: Solves the NFPA 1710 4-minute Maximal Covering Location Problem (`MCLP`) emergency station siting optimization problem across candidate siting budgets and demand weights.
3. **T3 (`t3_cascadia_m9_seismic_fragility_and_contraflow_evacuation`)**: Simulates M9.0 Cascadia-style subduction seismic PGA/PGV attenuation, buried-lifeline pipeline fragility curves across pipe material classes, and contraflow evacuation clearance dynamics, writing timeseries and scenario telemetry to `traffic_and_evacuation_metrics.csv`.

## Output Files
- `traffic_and_evacuation_metrics.csv` — Fundamental-diagram regimes and M9.0 Cascadia seismic contraflow evacuation clearance metrics.
- `urban_grid_validation_summary.json` — Consolidated telemetry metrics for T1, T2, and T3 (also mirrored to `app-preprints/releases/urban-grid-microscopic-traffic-resilience-validation-telemetry.json` in the parent monorepo).

## Reproducibility
```bash
cargo test --workspace
```
